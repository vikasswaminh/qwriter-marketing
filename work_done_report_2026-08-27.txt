2. EXPERT PROFILE PAGE REDESIGN - HIGH-DENSITY DASHBOARD LAYOUT
---------------------------------------------------------------
Target File: `src/pages/experts/[slug].astro`
- **Initial Structural Overhaul:** Discarded the fragmented, horizontally banded layout (multiple `<section class="os-section">` wrappers) in favor of a unified `<main>` flex container over a continuous gradient background (`linear-gradient(180deg, var(--warm-cream) 0%, #fffbf2 100%)`).
- **Aggressive Spacing Reduction:** 
  - Reduced the primary vertical flow gap from a sprawling `64px` down to `32px` / `40px` to drastically improve content density.
  - Reduced the padding within standard data cards (e.g., Tasks, Sample Chat) from `32px` to `24px` to achieve a tighter, more professional aesthetic.
  - Minimized the bottom CTA card padding from `56px 64px` to a sharp `40px`.
- **Hero Optimization:** The `ExpertGlyph` container previously enforced a rigid `aspect-ratio: 1` with massive `64px` padding, creating empty squares on desktop. Removed the aspect ratio, clamped the max-width, and reduced padding to closely hug the icon.
- **Asymmetrical Column Fix:** The "What it does" (Tasks) and "Sample chat" sections were previously bound in a rigid CSS grid (`grid-template-columns: repeat(auto-fit, minmax(400px, 1fr))`). If an agent had extensive tasks (like the HR agent), this forced a massive empty void below the sample chat. 
- **Masonry Task Grid:** Uncoupled the sections. Tasks are now rendered in their own highly dense grid (`repeat(auto-fit, minmax(320px, 1fr))`) that scales horizontally across the screen, eliminating the vertical empty space. The Sample Chat is now perfectly stacked as a full-width block beneath it.

3. PRESERVING LOCAL AUTHENTICATION TRAFFIC
------------------------------------------
Target File: `src/pages/experts/[slug].astro`
- **Issue:** The "Starter prompts" click action was configured to redirect users to an external production subdomain (`https://app.ollasuper.com/?expert=...`), bypassing the local marketing funnel.
- **Resolution:** Modified the `promptUrl` functional component to securely route traffic internally to the project's native `/signup` page.
- **Implementation:** `const promptUrl = (prompt: string) => '/signup?expert=${expert.slug}&prompt=${encodeURIComponent(prompt)}';`

4. 'PREVIEW PROMPT' INTERACTIVITY & CSS TOOLTIP REFACTOR
--------------------------------------------------------
Target File: `src/pages/experts/[slug].astro`
- **Layout Shifting Bug:** Using a native HTML `<details>` element for the prompt preview caused sibling cards in the `os-grid-4` to aggressively stretch vertically to match the opened card's height, ruining grid symmetry.
- **Tooltip Implementation:** Replaced the `<details>` component with an absolutely positioned CSS dropdown. 
- **Styling:** Used `position: absolute; top: 100%; z-index: 50; box-shadow: var(--shadow-lg);` on the hidden content block, and toggled visibility using a strict `.os-expert-prompt-container:hover .os-expert-prompt-content { display: block !important; }` CSS rule. 
- **Dynamic Theming:** Modified the "Preview prompt" trigger text to dynamically inject the active expert's assigned brand color (`style={\`color: ${expert.color};\`}`) and bumped font weight to 800 for maximum visual impact.
